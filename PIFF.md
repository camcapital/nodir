# NoDir

The NoDir repository, browsable as Piffs. Start with the [README](README.md) for what a Piff is, how to install NoDir and how to use it.

- Code lives in [crates/](crates/PIFF.md) (the shared library and the CLI) and [apps/](apps/PIFF.md) (the desktop app).
- [examples/](examples/PIFF.md) has trees to try NoDir on.
- [docs/](docs/PIFF.md) holds images for the README.

Releases are built by `.github/workflows/release.yml` when a `v*` tag is pushed. Hidden directories such as `.github` are not listed below.
